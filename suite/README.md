# Historical suite compatibility files

The current BP application is `overview/v1/serve.py` with Map modules in
`map/v1/`. This directory retains assets and helpers consumed by compatibility
paths. It is not a second supported application entrypoint.

Use [the current architecture](../ARCHITECTURE.md),
[product contract](../docs/PRODUCT.md) and
[deployment procedure](../docs/operations/DEPLOYMENT.md). Historical Map-only,
chat-only, fixed-port and export-copy instructions are superseded. Previous
revisions remain in repository history; they are not execution authority.
