# Overview

Status: current intent. See [the product contract](../PRODUCT.md) and
[operations design](OPERATIONS_EVOLUTION_2026_09.md).

Overview answers what needs the person's attention and gives enough workspace
context to choose the next useful action. Prioritize explicit decisions and
requested reading, explain watch items without claiming an agent is dead, and
keep personal notes distinct from execution gates.

WorkLane provides work state and gates; WorkForce provides configured and
observed execution; project registration supplies scope. Show source age and
unavailability. Empty and unavailable are different states. Assignment, a
heartbeat and repository activity must not be presented as equivalent evidence.

Work detail belongs in Work, execution detail in Agents, and project documents
in Projects/Map. Navigation should preserve the selected project and reader
context. Existing dark shared tokens govern paint; do not add fake activity,
placeholder metrics or a second independent work projection.

Verify useful populated, empty, stale, unavailable, keyboard and narrow-screen
states. A design study or a fixed tile count is not an implementation gate.
