# Settings

Settings describes this browser's preferences and the selected workspace's
responding build. Display preferences include fallback refresh interval and
motion. Values saved in localStorage apply to this browser; storage failure
must say that the setting applies only to the current page.

The live change feed is the normal update path; the interval is a polling
fallback. A connected transport does not establish that every data source is
healthy. Link to Connections for source status. System reduced-motion and the
saved motion setting apply consistently across surfaces.

Build identity comes from installed package metadata and deployment evidence,
never an unrelated package manager's version. Show the selected workspace and
observation state. Settings does not edit rosters, credentials, stop files or
host services. Keep keyboard access and active navigation visible on narrow
screens. See [operations](OPERATIONS_EVOLUTION_2026_09.md).
