# BluePrint 0.1.50

Public cut from consolidated main. This note is the citizen-facing summary.
It contains no credentials, host paths, or publish tokens.

## Aligns brew and pip

Homebrew Cellar and PyPI now share the same suite version: **0.1.50**.
WorkLane and WorkForce stay independent engines, both pinned at **0.1.9**.

```
pip install --upgrade 'protocolcity-blueprint[engines]'
# forever-compat alias:
pip install --upgrade 'protocolcity[engines]'
```

macOS: `brew upgrade protocolcity/tap/blueprint` after the tap formula
is pointed at this cut. The taught CLI remains **`blueprint` only**.
The app serves on **:8803**. Older :8801 / :8802 bookmarks redirect.

## What landed on this cut

- Work page is a live three-band board (now / waiting / parked), not a bulletin
- Agents floor pulses Working / Idle / Error from fresh evidence
- Overview Decide remainder door when more items exist than the face list
- Thin Calendar doors for Overview Due and Agents next-fire
- Quiet last-24h closes spark under Overview KPIs
- Timeline day/week activity histogram from the firings spine
- `blueprint upgrade` retires the old three-lane install onto the single app

POS is out of scope for this cut.
